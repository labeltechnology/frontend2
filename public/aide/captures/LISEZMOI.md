# Captures d'écran de l'aide en ligne

Déposez ici les captures prévues par les guides (étape 5 de la méthode).
Tant qu'un fichier manque, la page d'aide ne montre rien aux utilisateurs ;
le responsable de l'aide (Administrateur) voit l'emplacement et le nom attendu.

Règles :

- compte de démonstration avec des données fictives, jamais de données clients ;
- même taille de fenêtre pour toutes les captures (par exemple 1440 × 900) ;
- flèches et numéros ajoutés dans un éditeur d'images si besoin ;
- nom exact ci-dessous (minuscules, tirets), format PNG.
